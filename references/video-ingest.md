# 视频/图片采集指南 (Video & Image Ingest)

当用户**给出视频链接或图片、并希望整理成阵容笔记**时读此文件。目标不只是抓出 6 只宝可梦，而是把视频里的**玩法技巧、注意事项、对各热门对手的对策**也整理进笔记——这些信息主要藏在**解说字幕**里，而非单帧画面。

采集完成后，回到 SKILL.md 主流程：用「查权威数据库」核对名称/配招，再「询问是否建卡」，确认后用 `templates/阵容.md` 写卡。

---

## A. 在线视频（最常见）

### 1. 抓文字内容

调用同目录脚本（输出目录用本会话 scratchpad）：

```bash
python "<skill>/scripts/fetch_video.py" "<视频URL>" "<scratchpad目录>"
```

脚本会：
- 缺少 yt-dlp 时**自动 `pip install yt-dlp`**（无需 ffmpeg）。
- 生成一个汇总文件 `video_<id>.md`（含元数据 / 简介 / 字幕），并在 stdout 打印：
  - `output_file:` 汇总文件路径 → **读它**。
  - `subtitles:` 字幕状态：`none` 表示没抓到字幕（玩法信息会很有限，阵容多半需用户补截图）。

### 2. 从文字还原阵容

按优先级在 `output_file` 里找 6 只构成：
1. **简介里的 rental / 租借队码或队伍列表**——VGC 视频常直接贴出。
2. **字幕中点名的宝可梦/配招/道具/太晶**。
3. 标题/上传者作为旁证（如某知名构筑名）。

### 3. 从字幕提炼深度信息（笔记的价值所在）

通读字幕，归纳进 `阵容.md` 的对应章节：
- `## 玩法技巧`：核心连招、先手/对位逻辑、节奏与资源管理。
- `## 注意事项`：容易打错的点、读心提醒、什么情况别贸然出某只。
- `## 对策（对各热门对手）`：遇到哪些常见对手/构筑该怎么打、选出谁。

字幕（尤其自动字幕）会有口语、错字、滚动重复——按对战常识理解，必要时用「查权威数据库」核对专有名词，别原样照抄错名。

### 4. 还原不出阵容时——请用户补截图（不编造）

若简介+字幕都无法确定 6 只构成（例如 `subtitles: none` 且简介无队伍信息），**不要凭印象编阵容**。明确告诉用户并请其补一张队伍截图：

> 「这个视频没抓到能确定阵容的文字信息。能发我一张队伍截图吗（Team Preview / 队伍编成 / 租借队码画面都行）？我读图来还原阵容。」

截图随后走下方「图片采集」流程，并作为附件嵌入笔记。

> 注：本环境**未安装 ffmpeg**，不做自动抽帧。需要画面信息时一律走「请用户补截图」。

## B. 图片采集（用户截图 / 直接给图）

### 1. 读图识别

读取图片，识别尽可能多的信息：6 只宝可梦、可见的招式 / 道具 / 特性 / 太晶属性 / 性格。识别后用「查权威数据库」核对中文名与配招细节。

### 2. 保存为附件（必做）

图片要嵌入笔记，就必须先把**真实图片文件**存进 Obsidian 附件目录 `D:\Vaults\AIO\Attachments\`：

- **用户给了磁盘路径** → 直接复制过去。
- **用户在对话里粘贴/拖入图片** → piki 负责把它落盘到 `Attachments\`。先尝试定位 Claude Code 为该粘贴图保存的临时文件并复制；
  - 若能取到真实文件 → 复制进 `Attachments\`。
  - **若取不到原始文件** → 明确请用户把图片文件拖进来或给出磁盘路径。**绝不**用「看图重绘」的方式生成一张失真图冒充原图。

命名见 `references/note-conventions.md` 的「附件规则」（形如 `<阵容名>-team.png`）。

### 3. 嵌入笔记

在 `阵容.md` 的 `## 阵容图` 章节用 `![[<文件名>]]` 嵌入（按文件名引用，Obsidian 自动解析 `Attachments\` 下的同名文件）。

## C. 来源记录

视频链接 / 图片来源写入 frontmatter 的 `url` 字段（沿用「来源进 frontmatter、不另开『数据来源』章节」规范）。竞技数据另标赛季+模式。
