# 阵容对局分析 (Matchup Analysis)

**何时读**：判定用户意图是「给两套阵容、问这局怎么打／怎么选出」之后，动手之前。

目标不是把 12 只都点评一遍，而是回答三个问题：
**双方各自靠什么赢？我选哪几只？我最怕什么？**

先确认格式（`formats.md`）——单打 6 选 3 和双打 6 选 4 的选出逻辑完全不同。

---

## 第 1 步：角色标定

对 12 只各打标签。一次 `pokedb.mjs mon A B C … --matchup` 拿到属性/种族/相性，再逐个归类：

| 标签 | 识别信号 |
|---|---|
| 速攻手 | 高速 + 高攻，没有强化技，靠对位直接换血 |
| 强化清场手 | 带龙之舞/剑舞/蝶舞/自我暗示，赢法是「起来之后一打多」 |
| 破受 | 高攻 + 高威力技或穿盾手段，专门捅耐久队 |
| 受け（盾） | 高耐久 + 回复技/再生力，赢法是耗 |
| 中转 | 蜻蜓回转/伏特替换/急速折返/抛下狠话 |
| 速度控制 | 顺风/戏法空间/冰冻之风/电网/击掌奇袭 |
| 场面构筑 | 天气特性、场地技、双墙/极光幕 |
| 干扰 | 挑衅/打落/黑雾/替身/鬼火/电磁波 |
| 引导（双打） | 看我嘛/愤怒粉/避雷针/引水 |
| 保底 | 气势披带/坚硬脑袋/再生力/树果 |

**一队的身份是这些标签的多重集，不是一串宝可梦名字。**
两支完全不同的队可能是同一个战术类型；同一只宝可梦在两队里可能扮演不同角色。

---

## 第 2 步：战略轴（胜利条件）

核心问题：**「这队打算靠什么拿下最后一只？」**

按优先级找信号：

1. **同一类支援出现 ≥2 次** → 那就是轴。两只顺风者 = 顺风轴；两只空间使 = 空间轴。
   重复投资是最强的意图信号——没人会白带两个同功能的位置。
2. **高攻低速 + 队内有戏法空间** → 空间轴，胜利窗口是空间的 5 回合。
3. **强化技 + 铺路手段（引导/挑衅/双墙/牺牲打）** → 强化清场轴，关键变量是「能起几段」。
4. **天气发动特性 + 天气受益者 ≥2** → 天气轴。
5. **高耐久 + 回复 + 状态技 + 钉子（单打）** → 消耗轴，胜利条件是回合数与 PP。
   注意 Champions 超时判双负，纯拖时间在 Champions 不成立。
6. 以上都不成立 → **泛用好队（goodstuff）**，其轴是「对位优势 + 中转累积」，
   分析重心转向逐对位，不要硬套一个不存在的轴。

**输出必须是一句话**：「A 队的轴 = 顺风下振翼发+铁臂膀的双输出；B 队的轴 = 空间下白马蕾冠王一打二」。

然后看**两轴是否互斥**——顺风 vs 空间、晴 vs 雨、快攻 vs 空间，
这类互斥点往往就是整局的胜负手：谁先建立自己的场面，谁就赢了一半。
互斥时要明确写出「抢场面的窗口在第几回合、谁先动手」。

---

## 第 3 步：威胁矩阵（两遍法）

6×6 全部精算是 token 和时间的黑洞。**先粗筛，再精算。**

### 粗筛（零次 calc）

用 `pokedb.mjs` 的相性、速度、种族值给每格标四态：

- `W` 我方稳赢（打得动、扛得住、或速度压制）
- `L` 我方稳输
- `T` 待定——**需要真实伤害才能判断**
- `-` 互不相干（谁也打不动谁）

判据就三条：属性相性倍率、速度先后、攻防种族差。这一步靠脑子就能做完。

### 精算（只算 `T` 格）

把所有 `T` 格写成**一个** `calc.mjs` 批量输入，一次跑完。典型 8~20 条。
只算这三类，其余不算：

- **疑似 OHKO 边缘**的（85%~115% 区间，随机数会翻转结论的）
- 决定**要不要集火**的（双打：一只打不掉、两只打得掉？）
- 决定**能不能吃住**的（我这只换进去会不会直接被秒）

对手配置未知就写 `"spread": "unknown"`，拿双基准区间——
**别挑一行当结论**，区间本身就是后面的读心点。

### 输出

一张紧凑的表 + 三行结论：

- 「我方最难处理的是 X」——没有任何一只能稳定解决它
- 「我方的免费对位是 Y」——可以放心换进去赚回合
- 「关键速度线：Z 快过我方全员，除非顺风」

---

## 第 4 步：阈值清单

三类，**每条都必须是具体数字**，不能是「比较快」「比较肉」：

- **速度线**：谁在裸速/围巾/顺风/空间下快过谁，含同速猜拳点（`pokedb.mjs speed` 的 `TIE` 行）。
  Champions 单项上限 32，大家都点满就是纯拼种族值，同速比主系列更常见。
- **确定数线**：几发带走、双打要不要集火、+1 之后能不能过线。
- **耐久线**：能不能吃住对方主力一发。
  `unknown` 的双基准正好给出「他堆了耐久就吃得住，裸的就吃不住」——**这句判断本身就是第 6 步的读心素材**。

---

## 第 5 步：选出

**这是本节最实用的部分。两种格式的逻辑完全不同，不要混用。**

### 单打 6 选 3

选出是**覆盖问题**，不是「选最强的三只」。判据依序：

1. **对面轴的停止器必带**——谁能挡住他的清场手/空间/天气？没有停止器就等于把胜利条件送给他。
2. **我方的轴 + 至少一个铺路/中转**——只带输出没有起手手段，轴立不起来。
3. **一个泛用换入承受面**——能吃住对面 2 只以上的主力技，且有回复或能反打。
   没有这个，你每次换人都在掉血，三只很快就撑不住。

**必须显式做二阶推理**：「他看到我的队，会选出 X 来针对我的 Y，所以我改带 Z」。
单打的选出本身就是**同时进行的猜拳的第一层**——你在猜他的选出，他也在猜你的。
把这层推理写出来，不要跳过。

**另需单独决定首发**，并区分两种首发：
- **首发出战**：这只要真打，负责建立优势或换血。
- **首发即换**：turn-1 硬换（送一个身位换取信息或对位）。单打这是常规操作，不是失误。

### 双打 / VGC 6 选 4

真正的单位是**「前二 lead + 后二 back」的组合**，不是四只的集合。
同样四只，不同的 lead 是完全不同的两套打法。

判据：

1. **lead 的 turn-1 存活性**——对面能不能用集火（双打同一目标）或击掌奇袭+攻击，
   在第一回合直接秒掉我方一只？会的话这个 lead 不能用。
2. **速度控制归属**——谁的顺风/空间先成立？如果我要抢顺风，
   **我的顺风者必须活过第一回合**，否则整个计划落空。
3. **back 必须含翻盘角色**——对面轴成立之后的解法。back 全是输出等于没有 plan B。
4. **不选两只被同一属性通打的**——一发范围技双杀就直接输了。
   粗筛表里如果两只在同一列都是 `L`，警报。
5. **胜利手段必须配一个保姆**——保护/引导/击掌奇袭/威吓，
   至少一个能替核心挡下第一波集火的手段。

### 产物格式（固定）

```
选出：A / B / C / D，首发 A + B
理由：① … ② … ③ …
不选 E 的理由：…
对面最可能的选出：…（以及他为什么这么选）
```

单打把「首发 A+B」换成「首发 A（打／即换）」。

---

## 第 6 步：对策要点（必须具体含这 7 项）

不要写「注意对面很强」这种没有操作价值的话。逐项给：

1. **威胁排序 #1**——哪一只必须最先解决？用谁、几发、要不要集火。
2. **绝不能给的窗口**——不能白送他起龙之舞/剑舞/顺风/空间/铺钉的自由回合。
   **写明这个窗口会在哪个回合、什么局面下出现**，否则这条没法执行。
3. **关键速度线与道具猜测**——他若带围巾，速度线翻转成什么？翻转后我最坏结果是什么？
4. **我方必须被保护的核心**——谁死了这局就没了？用什么手段保（保护/引导/换/弃子）。
5. **胜利路线的时间点**——「第 3~4 回合必须建立顺风并拿掉他的 X，否则转入劣势」。
   没有时间点的计划等于没有计划。
6. **对面的常见陷阱**——保护读、引导、替身、先制技、气势披带、树果回血、复活祈祷。
7. **未知信息的分支预案**——他亮出未预料的道具/招式时，切到哪条备用路线。

> 第 3 和第 7 项的信息来源是 **pokechamdb 的使用率**，不是凭感觉。
> 「他大概率带围巾」要有依据；查一下当前赛季这只的道具分布再说。

---

## 输出规范

默认**先简后详**：先给结论层（战略轴一句话 + 选出方案 + 最大威胁 + 时间点），
把威胁矩阵、伤害确定数、速度线明细放进可展开的小节。
用户说「详细/展开」再全部铺开。

分析完可以问一句是否整理成笔记（`templates/阵容.md` 的章节与本文件逐节对应），
但**不要每次都问**——只在这次分析确实产出了值得沉淀的东西时问。
