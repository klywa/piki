# 格式与规则差异 (Formats)

**何时读**：做阵容对局分析或局面决策之前读一次；用户同时涉及多种格式时也读。

piki 支持三套规则。**分析前必须先确定是哪一套**——搞错了，速度线、选出人数、
能不能用某个道具全都会错。用户没说明时，默认 **Pokémon Champions**（这是他的主场），
但如果输入里出现太晶、突击背心、讲究头带这类 Champions 没有的东西，说明多半是主系列，要反问一句。

| | Champions 单打 | Champions 双打 | 主系列 SV / VGC |
|---|---|---|---|
| `--format` | `champs-single` | `champs-double` | `sv-single` / `sv-double` / `vgc` |
| 等级 | 50 固定 | 50 固定 | 50（VGC）/ 100（Smogon 天梯） |
| 选出 | 6 选 3 | 6 选 4 | 单打 6→3 / VGC 6→4 |
| 努力值 | 66 能力点，单项上限 32 | 同左 | 508 努力值，单项上限 252 |
| 个体值 | 无此概念（公式固定按 31） | 同左 | 0~31 可调 |
| 性格 | 有，×1.1 / ×0.9 | 同左 | 有 |
| 太晶 | **无**（未解禁） | **无** | 有 |
| Mega | **有** | **有** | 无（第九世代已移除） |
| Z招式 / 极巨化 | 无 | 无 | 无 |

## Champions 的能力点制

**1 点 = 50 级下最终面板 +1**（性格修正之前）。总共 66 点，单项最多 32 点。

两个能直接心算的等价关系，很好用：

- **无投入时，实数值 = 种族值 + 20**（HP 是 **种族值 + 75**）
- **32 点 = 第九世代的 252 努力值 / 31 个体值**——面板完全相同

第二条意味着**你原有的第九世代确定数经验可以直接迁移**：主系列里「252 满攻打得掉」的对位，
在 Champions 里「32 点满攻」结果一样。

只是总量小得多：66 点大约只够**两项点满（32+32=64）**，剩 2 点。
所以 Champions 的配置比主系列更「非此即彼」——很难同时兼顾输出与耐久，
这本身就是选出和读心的重要信息：**看到一只快，就基本可以推断它没堆耐久。**

单项上限 32 也意味着**速度线更密集**：大家都点满 32 就纯拼种族值，
同速的情况比主系列更常见——记得用 `pokedb.mjs speed` 的 `TIE` 行确认。

> 性格修正乘在 (种族+点数+20) 的整个和上、最后取整，不是乘在点数上。
> 脚本已经处理好了，但如果你要手动验算，别把顺序弄反——会差 1~3 点面板，
> 而 1 点面板足以翻转先手或确定数。

## Champions 的道具池

道具池**比主系列小，而且随版本逐步解禁**。截至赛季 M-5：

- **可用**：讲究围巾、气势披带、剩饭、生命宝珠、光之黏土、焦点镜、广角镜、
  文柚果、木子果、全套属性半减果
- **尚未实装**：讲究头带、讲究眼镜、突击背心、进化辉石、凸凹头盔、剧毒宝珠、火焰宝珠、
  强力香草、弱点保险、隐密斗篷、厚底靴、作弊骰子、黑色污泥、气球、红牌、逃脱按键等

这条**直接影响配招建议和伤害计算**：在 Champions 里推荐一套「突击背心 + 讲究眼镜」的配置是无效建议。
`calc.mjs` 会对未实装道具发出 `⚠` 警告，但你在给建议时就该避开。

道具池会变（生命宝珠、光之黏土都是上线时未实装、后来开放的）。
权威清单在 `data/champions-rules.json` 的 `items` 字段，**发现某个道具已解禁就直接改那个文件**。
拿不准某个道具当前能不能用时，去 pokechamdb 看实际使用率——有人在用就是能用。

## Champions 的其他改动

这些不影响伤害，但影响**风险评估和行动顺序**：

- **麻痹的「无法行动」概率从 25% 降到 12.5%**。做风险评估时别再按 1/4 算——
  麻痹作为进攻手段比主系列弱了一半，作为速度控制则依然有效。
- **冰冻最迟第 3 回合必定解冻**；睡眠回合数缩短。都比主系列可控，
  意味着状态技的「锁死」价值下降。
- **超时判双方负（平局）**，不再按剩余数量/血量判定。
  这抹掉了主系列里「拖时间保优势」的整条战术线——领先时不能靠耗时赢。
- **Mega 进化的结算时点在「回合内换人之前」**。这是 Champions 专属改动：
  意味着对手换人后你的 Mega 已经完成，Mega 后的速度/属性对本回合就生效。

## 什么时候该去查 web

本地库是**主系列 Showdown 数据的快照**，它不知道 Champions 的环境。

| 问题类型 | 用哪个 |
|---|---|
| 属性、种族值、招式威力/命中/PP、相性、学习合法性 | **本地库**（`pokedb.mjs`）——确定性事实 |
| 伤害、确定数、耐久线 | **本地库**（`calc.mjs`） |
| 使用率、常见配招、道具/性格分布、拍档搭配 | **web**（pokechamdb，见 `sources.md`） |
| 当前赛季环境、强势阵容、赛事队伍 | **web** |
| 某个宝可梦/招式在 Champions 是否存在、是否被改动 | **web**——本地库查不到不等于游戏里没有 |

`pokedb.mjs` 返回 `NOTFOUND … 请走 web 源`时，这就是在告诉你该切换到 web 了。
**不要用一只相近的宝可梦顶替，也不要用主系列的数值假装是 Champions 的。**

## 太晶／Z招式／极巨化的状态

它们**没有从游戏里删除**，只是当前规则档（至 M-A / M-B，赛季 M-4 / M-5）尚未解禁。
所以：

- Champions 相关的回答和笔记里**不要引入太晶**；`calc.mjs` 会直接拒绝 `teraType`。
- 但也不要说「Champions 永远没有太晶」——**说「当前规则未解禁」更准确**。
- 日后解禁时，把 `data/champions-rules.json` 的 `gimmicks.tera` 改成 `true` 即可，脚本会自动跟着放行。
